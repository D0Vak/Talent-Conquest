# 武将のドット絵 素材の仕様書

武将のドット絵を、コードで描く絵から **PNG の部品を重ねる絵** に置きかえるための決まり。
ドット絵の生成AI（PixelLab・Retro Diffusion など）や Aseprite で部品を作り、`assets/sprites/` に置く。

- 部品がそろっていないうちは、今のコードで描いた絵が代わりに出る（少しずつ置きかえられる）
- 作り方の流れ → 「6. 作り方」 / 最初に作るもの → 「7. 最初の試し」

---

## 1. 全体の作り（部品を重ねる）

1人の武将は、部品を下から順に重ねてできる。どの部品も **同じ大きさの透明なキャンバス** に、**同じ立ち姿の位置** で描く。

| 順番（下から） | 部品 | どんなときに使うか |
|---|---|---|
| 1 | 竜 | 飛竜（翼は体の後ろ） |
| 2 | マント | 階級の段が「官」以上で、ローブでないとき |
| 3 | 馬 | 騎兵 |
| 4 | 脚（立ち） ／ 脚（乗った姿） | 立っているとき ／ 馬・竜に乗っているとき |
| 5 | 体（鎧） ／ ローブ | ふつう ／ 魔導 |
| 6 | 顔 | いつも |
| 7 | 後ろ髪 → 前髪 | いつも（後ろ髪は顔の下に重ねる） |
| 8 | 小物（眼帯・仮面） | ときどき |
| 9 | 兜 ／ フード・とんがり帽子 | 兜は重装・将・一部の人。フードは魔導 |
| 10 | 武器 | いつも（得意武器） |
| 11 | 大盾 | 重装 |
| 12 | 魔導書 | 魔導 |

コードが描くもの（素材はいらない）：勲章の胸飾り、英雄大綬章のたすき、ベテラン・英雄の光、光る卵のオーラ。

## 2. 共通の決まり

| 項目 | 決まり |
|---|---|
| 大きさ | **48×48 ドット**（今と同じ。地図では28〜240ドットに拡大・縮小して出す） |
| 体つき | 約3頭身。正面よりやや斜め（今の絵と同じ）。両足を少し開いて立つ |
| 足の位置 | 足の裏が **y=45**（いちばん下の行が y=47）。体の中心は **x=24** |
| 手の位置 | 左手（絵の左）が **x=13〜15・y=26〜27**、右手が **x=32〜34・y=26〜27**。武器はこの手に持たせる |
| 光 | 左上から当たる。明暗は4段階（光・明・中・影）くらい |
| 縁どり | 外側に1ドット、濃い紫黒 **(26, 20, 38)** |
| ぼかし | **使わない**（アンチエイリアスなし）。色は部品ごとに16色くらいまで |
| 背景 | 透明（PNG の透明） |
| 形式 | PNG。1部品＝1ファイル |

### 色を差しかえる部分（キー色）
国の色・髪の色・勲位の縁どり・馬の毛色は、武将ごとに変わる。そこは **下のキー色で塗る**。ゲームがその人の色に置きかえる。
キー色以外の色は、そのまま出る。

| 差しかえる色 | 光 | 明 | 中 | 影 |
|---|---|---|---|---|
| 国の色（服・マント・旗・鞍） | (255, 128, 255) | (255, 0, 255) | (200, 0, 200) | (140, 0, 140) |
| 髪の色 | (128, 255, 128) | (0, 255, 0) | (0, 200, 0) | (0, 140, 0) |
| 勲位の縁どり（鎧のふち・腰ひも） | (128, 255, 255) | (0, 255, 255) | (0, 200, 200) | (0, 140, 140) |
| 馬の毛色 | (255, 255, 128) | (255, 255, 0) | (200, 200, 0) | (140, 140, 0) |

- AIはキー色をそのまま使ってくれないことが多い。**AIでふつうの色で作ってから、Aseprite で該当の部分だけキー色に塗りかえる**
- 4段階ぴったりでなくてよい。近い色はいちばん近い段に置きかえる

## 4. 気をつけること

- **全部の部品で、立ち姿をそろえる**。1枚だけ体の位置がずれると、重ねたときに崩れる
- 鎧（`body/`）は腕と手まで描く。手は `head/face.png` と同じ肌の色にする
- 武器は、手の位置（2.）から伸ばす。持ち手は手に重なるように
- 馬・竜は、乗り手の腰（y=27〜33あたり）に鞍が来るように
- 馬に乗ったときに馬の頭が乗り手に隠れないよう、頭と首は絵の左はしに出す
- ローブ（立ち）は、脚の絵を使わずに裾が足元まで届く

## 5. AIに渡す指示文（例）

英語のほうが通りやすい。下の文に、作りたい部品の説明を足す。

**共通**
```
pixel art, 48x48, chibi, 3 heads tall, fantasy medieval soldier, three-quarter front view,
standing with feet apart, light from top-left, 1px dark outline, no anti-aliasing,
limited palette, transparent background
```

**例：鎧（板金・長）**
```
(共通の文), full plate armor, pauldrons, silver steel, no weapon, no helmet
```

**例：馬**
```
pixel art, 48x48, side view horse facing left, saddle, transparent background,
1px dark outline, no rider
```

- 参考画像に絵柄を合わせる機能（PixelLab のスタイル参照など）があれば、**1枚目に気に入った武将を参考画像にして**、残りを作る
- 下絵が欲しいときは、今のコードの絵を部品ごとに PNG で書き出せる（頼んでもらえれば用意する）

## 6. 作り方（流れ）

1. AIで、**1人の武将の全身**を作る（気に入るまで作り直す）
2. Aseprite で、その全身を部品に分ける（体・脚・頭・髪・武器…をレイヤーに切り分ける）
3. 部品を 2. の位置に合わせ、色を差しかえる部分をキー色に塗りかえる
4. 部品ごとに PNG で書き出して、`assets/sprites/` の決まった場所に置く
5. ゲームを起動して、重ねた絵を確かめる
6. 同じ全身を参考画像にして、ほかの段の鎧・ほかの武器を作る（1〜5のくり返し）

## 7. 最初の試し

全部を作る前に、次の5枚だけで試す。

| ファイル | 中身 |
|---|---|
| `head/face.png` | 顔 |
| `hair/front_short.png` | 短髪 |
| `body/tier3.png` | 板金の鎧（長） |
| `legs/tier3.png` | 板金の脚 |
| `weapon/sword.png` | 剣 |

この5枚が置かれたら、PNG を読みこんで重ねる仕組みに書きかえる。ない部品は今のコードの絵で補う。

## 8. 決めていないこと

- 絵の大きさを48×48のままにするか（大きくするなら、この仕様書の座標をすべて直す）
- 歩く・攻撃するなどの動き（アニメーション）を作るか
- 主人公の3人だけ、専用の絵にするか
- 生成AIの利用規約（作った絵を売り物のゲームに使ってよいか）の確認
