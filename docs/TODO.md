# テストプレイの課題（2026-10-19 更新）

作る順番：**0. すぐ直すもの → 兵科 → 記録 → 会戦 → 国の特性 → 戦死・慰霊碑・異名 → お金と食料・拠点 → 爵位・家名 → 外交**（くわしくは DESIGN.md の「作る順番（新）」）
それぞれの課題が、どの段階で解決するかを書いておく。

## 0. すぐ直すもの（不具合・見た目）

| 課題 | 原因の見当・直し方 |
|---|---|
| 壊滅した部隊が、元の城まで半強制的に帰される | **直した**（壊滅すると一番近い味方の城へ落ち延びる。帰り道も味方の領地だけを通る） |
| 勢力を滅亡させられない | **直した**（最後の城・町が落ちた瞬間に滅亡。残った部隊が取り返していたのが原因） |
| 地図に塗り残しが出る | **直した**（通っただけのマスは一時的な占領。毎月、部隊がいなければ地域の持ち主に戻る） |
| 険しい山なのに通れるルートがある | **直した**（通れない「険しい山」と、地形を塗り直す道具 terrain_editor.py。塗り直しは自分で） |
| 通れるはずのルートが通れず、回り道をさせられる | **直した**（同上。峠や谷を塗って通れるようにする） |
| 部隊が集まりすぎて、拠点をクリックしているのか分からない | コマと拠点の重なり方を見直す |
| 敵と重なって、いるのかいないのか分からない | 同じマスに敵味方がいるときの表示を変える（左右に分ける、など） |
| 強い将校なのに目立たない。勲章も目立たない | **直した**（48×48のドット絵。階級で鎧、勲位で縁どり、勲章で胸飾り、ベテランと英雄に光）。見た目はまだ改善したい |
| マップが狭く感じる | **直した**（4倍の高解像度の絵、ズーム5倍まで。寄ると城・町をドット絵で描く） |

## 1. 兵科で解決するもの

| 課題 | 兵科でどう変わるか |
|---|---|
| 地の利が活かせていない | 兵科ごとに得意・苦手な地形がある。騎兵は平地、歩兵は森、重装は山 |
| キャラの違いが分かりづらい | 兵科の適性（S〜D）と兵科の称号で、「騎兵の名手」「弓の名手」のような個性が出る |
| スキルがあまり役に立っていない | 兵科や地形と組み合わさるスキルにする（例：森で伏兵、平地で突撃） |
| 「防御」が戦いに使われていない | 防御が高いほど、受ける損害が減るようにする |

## 2. 国の特性で解決するもの

| 課題 | 国の特性でどう変わるか |
|---|---|
| 帝国と王国が弱く、独立勢力と民族連合が強い | 国ごとに強み・弱みをつけて調整する（帝国は守備隊が強い、など） |
| 国の数は多くなくていい。でも独立や特性はほしい | 国の数は今のまま。国の中から独立する勢力（反乱）が出るしくみを作る |

## 3. お金と食料・拠点で解決するもの

| 課題 | 拠点のしくみでどう変わるか |
|---|---|
| 拠点にいる意味が回復しかない | 拠点ごとに特殊効果をつける |
| 中心に兵を置くメリットがない | 政治をした土地にバフ、徴兵、放っておくと一揆、など |
| 訓練させるのがめんどくさい | 拠点に「訓練所」を置けば、そこにいるだけで自動で鍛えられる、など |
| 部隊を持つ将校が、攻撃・防御の訓練を選ぶ意味がない | 同上（拠点にいる間の過ごし方に意味をもたせる） |

拠点の特殊効果のアイデア：

- 常備兵（守備隊が強い）
- ある兵科の兵が集まりやすい（騎兵の牧場、弓の工房 など）
- 温泉：兵の回復が速い
- 鉱山：強い装備が作りやすい
- 金山・大商人街：お金が稼ぎやすい
- 大農場：食料が多くとれる
- 一揆：政治をしないと反乱が起きる

## 4. 外交で解決するもの

- 交易、同盟、不可侵、包囲網（連合）
- 敵どうしの戦いで滅亡がほとんど起きない（敵は近くの城・町をばらばらに狙うため）。包囲網や「弱った国を集中して攻める」考え方で、国が滅ぶドラマを作る

## 将校・育成のバランス（段階をまたぐ）

| 課題 | 考えられる直し方 |
|---|---|
| 下の階級は上がりやすいが、上の階級に上がりにくい。全員が中間の将校になり、誰が上官か分からない | 上の階級に**人数の上限**をつける（将軍は国に○人まで）。上官と部下の関係（軍団）をはっきり見せる |
| 歴史の30年で、老将の攻撃が400〜800まで伸びる（主人公は55〜90）。勝つたびの伸びが積み重なるため | いったん「それだけ強い」として遊んでみる。アンバランスなら、勝ったときの伸びを小さくする（全体か、歴史のあいだだけ） |
| 階級ごとの兵数の差が大きく、ある程度昇進しないと戦えない。「昇進させない」メリットがない | 低い階級にも役割をつける（偵察、少人数で速く動ける、副官として強い、など） |
