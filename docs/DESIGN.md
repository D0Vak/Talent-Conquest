# Talent Conquest 設計メモ

2026-10-24 に Python 版（Talent-Conquest-Game）から、この Unity 版に移した。これからの決めごとはここに書く。

## コンセプト
- オリジナルの部下を一から育てて、国を大きくしていく軍事シミュレーション
- 政治よりも軍事が中心
- 参考：信長の野望・三国志・FE・HOI4（ドラクエ・FFのような1人を操作するRPGではない）
- 部下は50〜100人程度。ランダムに生成され、ときどき「光る卵」（高ポテンシャル）がいる
- イケメングラフィックを使う

## ゲームの骨組み（決定）
「マスを取るゲーム」から「**武将が軍を率いて、要所を取るゲーム**」へ。

- **時間**：一時停止つきリアルタイム（HOI4型）。1日ずつ自動で進み、止めて命令を出せる。速さも変えられる
- **武将＝地図の上のコマ**：武将1人が1つの軍団を率いて、数日かけてマスを移動する
  - 地形で移動の速さが変わる（平地は速く、山は遅い）
  - 敵の国にも名前のある武将がいて、軍団として動く
  - 「この峠には山岳戦が得意なあいつを送る」という判断が生まれ、育成の意味になる
- **国力**：マスの数も大事。それと**同じくらい**、城・国・指揮官の特性で大きなバフがかかる
  - 兵・お金・食料を生むのは主に城と町。鉱山・農地・港など町ごとに役割がある
  - 小国でも、特性が噛み合う場所で戦えば大国と渡り合える
- **特性**：国・城・武将それぞれにつける（例）
  - 主人公の国：光る卵が見つかりやすい
  - 東の帝国：兵は多いが、遠征すると士気が下がりやすい
  - 民族連合：山・丘での守りが強い。鉱山から良い武器
  - 海の国：海を渡って移動できる / 河の国：川沿いの守りが強い / 中原の国：兵の回復が速い
  - 城：堅城、兵站の拠点 など
  - 武将：兵科適性、スキル、固有必殺技（下の「兵科・スキル」）

### 作る順番（最初に決めたもの。1・2・5はできた。今の順番は下の「アイデア」の「作る順番（新）」）
1. ~~時間が流れる。自分の武将のコマが地図を移動し、敵のマスを占領・城を包囲できる~~（できた）
2. ~~敵の国にも武将のコマ。コマどうしがぶつかると戦闘~~（できた）
3. 城と町の価値（兵・お金・食料）
4. 特性（国・城・武将）
5. ~~成長・昇進・頭角を現す~~（できた）

## 育成のしくみ（決定）
育成は「見つける → 育てる → 報いる」の3段階。

### 見つける（新しい武将）
- **基本は拠点で登用**：毎月、自国の拠点に登用の候補が何人か現れ、その中から選ぶ
- **たまに戦場での叩き上げ**：戦いに勝つと、兵の中から頭角を現す者が出ることがある
- **たまに捕縛した敵の寝返り**：敗れた敵の武将を捕らえ、配下に加わることがある
- 候補の潜在能力ははっきり見えず「80〜100？」のような幅で見える。光る卵は立ち絵にオーラ

### 育てる
- **訓練**：自国の城・町にいる武将に方針（攻撃・防御・休養）を決めると、毎月少しずつ伸びる。安全だが伸びは小さい。鍛える能力が高いほど伸びにくい（能力100なら基本の量、400なら4分の1）
- **実戦**：戦いに勝つと大きく伸びる。負けると兵を失う
- 若いほど伸びやすい。成長タイプ（早熟・普通・晩成）で、伸びる時期と衰える時期が変わる

### 報いる
- 昇進：功績で階級が上がり、率いる兵数が増える

- **刻み**：5000までは500刻み、その上は広げる。段階が細かいので、こまめに昇進できる（「上の階級に上がりにくい」課題への答え）
- **昇進させない選択**：昇進はボタンで決めるので、わざと階級を上げない武将（ガープ中将のような人）も作れる
- **功績**：交戦1勝＝功績10。同じ兵数に届くまでの手間は、古い10段階とほぼ同じ（兵4000：古い表で380、新しい表で350）
- **所属**：精鋭兵長までは、上官の部隊に**副官**として入る。上官と一緒に戦い、勝つと一緒に成長する。副官のスキルも部隊に効く
- 部隊長に昇進すると独立して、自分のコマを持つ（「育てた部下がついに一軍を率いる」瞬間）
- **旅団・師団**も同じ兵科の部隊（1人1つの兵科・武器。混成ではない）
- **階級の表示に兵科名は入れない**（「上級師団長」だけ）。兵科と得意武器は別の欄に出す。例外は特殊上級職（魔導覇将・飛竜聖天将・軍神 など）
- 国によって階級の呼び名を変えてよい。湿地の国は傭兵団風（新しい21段階に合わせて作り直す）
- **人数の上限**（国ごと）：大将軍5人、元帥3人、大元帥1人。席が空かないと昇進できない
- 「将軍」として扱う（将討章の条件）のは統軍将から
- 保留：特殊上級職の条件、湿地の国（傭兵団風）の呼び名（今は仮）

### 功績の表し方（決定）
- **勲位**：これまでの功績の合計で自動で上がる「実績の格」
  - 鉄(0) → 銅(30) → 銀(100) → 金(200) → 白金(350) → ミスリル(550) → アダマンタイト(800) → オリハルコン(1200)
- **勲章**：大戦果を立てたときに授かる。1つもらうごとに**潜在能力の天井+10**（化けた証）

| 勲章（名前は仮） | 条件 |
|---|---|
| 獅子章 | 交戦の始まりで相手の強さが自分たちの2倍以上だったのに勝つ |
| 城砕章 | 城を5つ落とす |
| 堅守章 | 自国の城・町のマスでの交戦に3回勝つ |
| 救援章 | 味方の城を包囲している敵と戦って勝つ |
| 将討章 | 敵の将軍を破る |
| 歴戦章 | 戦線にいた日数が合計5年（移動・包囲・交戦の日だけ。拠点で待機は数えない） |
| 英雄大綬章 | ほかの勲章を5種類以上集める（最強の証） |

- 英雄大綬章のバフ：部隊の強さ×1.3、受ける損害×0.8、同じマスの味方の部隊も強さ×1.1
- **潜在能力の成長**：勝つたびに潜在能力が上がる（天井まで）

## 肩書き（決定）
1人の武将が、次の4種類の肩書きを同時に持てる。「平民出身の大将軍」や「侯爵家の新米」が生まれる。

| 種類 | 何を表すか | 例 | どう手に入るか（案） |
|---|---|---|---|
| ① 軍の階級 | 軍での地位。率いる兵数が決まる | 部隊長、筆頭師団長、元帥 | 功績で昇進 |
| ② 爵位 | 生まれ・家柄・身分 | 平民、騎士爵、準男爵、男爵、子爵、伯爵、辺境伯、侯爵、公爵、大公爵、王族（国王・王子）、皇族（皇帝・皇子） | 生まれつき＋大きな手柄で叙爵 |
| ③ 官職 | 国の仕事 | 領主、代官、宰相、大臣、右大臣、左大臣、執政官 | 任命する（内政を作るときに一緒に） |
| ④ 称号 | 個人の武勇や才能の証 | 聖騎士、剣聖、騎士団長、守護者、大司教、賢者、大魔導士 | 実績を達成すると授かる |

- **性別**：基本は男性。ごくまれに（全体の約2%）、才能ある女性武将・姫武将が出る（2026-10-20 に「全員男性」から変えた）
- **爵位の効果**：私兵（率いる兵数に上乗せ）、忠誠・寝返り（高いほど寝返りにくい）、領地・内政（内政を作るときに）
- **魔法・教会がある世界**：「知力」「魔力」「聖力」などの能力値を足す。魔導士は魔法で戦い、聖職者は兵を癒す など
- **素質（決定）**：人はみな**魔力持ち**か**聖力持ち**（約49%ずつ）。ごくまれに、どちらも持たない**無者**（約2%）が生まれる
  - 魔力持ちは誰でも魔導・魔闘を、聖力持ちは誰でも聖兵を率いられる。魔力・聖力の高さは強さに効く
  - 無者は魔法の兵科を率いられない。かわりに攻撃・防御が生まれつき約1.4倍で、魔導・魔闘・聖兵から受ける損害が2割減る
- **称号の見た目**：称号を持つと、ドット絵に装備が重なる（剣聖なら大剣、聖騎士なら白いマント、王族なら王冠 など）

## 部下の成り上がり（案B：決定）
- 兵はただの「兵数」。一人ひとりに能力値はない
- 戦うと、兵の中から**ときどき名前つきの部下が「頭角を現す」**
- 頭角を現した部下は**新兵**から始まり、手柄を立てて**昇進**していく（階級は上の「軍の階級」）
- 名前つきの部下は全部で50〜100人程度（規模は変えない）
- 光る卵が見つかる入口：**戦場で頭角を現す / 町で登用する / 敵から捕縛する**

## 兵数
- 固定の上限（1000など）はなくす
- 1人が**率いられる兵数**は、階級と能力で決まる
- 国全体の兵は**領地（人口）から集まる**。領地が増えるほど兵も増える
- 狙い：兵だけ貯めても勝てず、率いる部下を育てる必要がある

## 歴史を回す（決定）
- ゲームを始める前に、裏で**30年**進める。自国も含めて全部の国が自動で戦い、登用し、昇進し、亡くなる
- **国境は変わらない**（毎月、最初の形に戻す）。国は滅びない。戦いの経験・勲章・階級だけが残る
- 終わると、老将・将軍・勲章持ちがどの国にもいる状態から、31年4月に始まる。そこへ主人公の3人が加わる
- 国ごとの武将の数は、城×2 ＋ 町÷2（最低6人）。敵の国は、この数まで登用して補う

## 地形・地図
- 狙い：「攻めれば必ず取れる」をなくし、攻める場所を選ぶ意味をつくる
- まずは戦闘の強さに倍率を掛けるだけで始める（数値は仮）

| 地形 | 効果 |
|---|---|
| 平地 | ×1.0。大軍同士の決戦場 |
| 森 | 守る側 ×1.3。伏兵・奇襲（あとで） |
| 山・峠 | 守る側 ×1.8。少数で大軍を止める要衝 |
| 川を渡って攻める | 攻める側 ×0.7。渡河点が防衛線になる |
| 城・砦 | 守る側をさらに ×1.5 |

- あとで足す：天候・季節（川の凍結、ぬかるみ）、火攻め、水攻め、高台からの射程、視界の霧

### 地図の作り
- 見た目の層：マップ生成サイトで作った大陸の絵を背景にする
- データの層：**拠点と道**（点と線）で作る。信長の野望型
  - 各拠点が地形・城の有無を持つ
  - 隣かどうかは道でつながっているかで決まる
  - **チョークポイント**（峠・橋）と**バイパス**（遠回りの森の道など）を道のつなぎ方で作る

### 世界（案）
- 仮想世界の仮想国どうしの戦い。規模は大陸全体
- 南北に走る大山脈が大陸を東西に分ける。越えられるのは2〜3か所の峠だけ
- 西側を大河が流れ、渡れるのは橋と浅瀬のみ
- 南に内海。海から回り込むルートもある
- 中央に豊かな盆地（穀倉地帯）。守りにくく、常に争いの中心になる
- 北西の半島に、背後が海で守りやすい小国（初期国の候補）
- 東の平原に大国、山脈沿いに小国が並ぶ緩衝地帯

## 能力値とポテンシャル
- 能力値（攻撃・防御など）に**上限はない**。戦うほど上がる
- 初期能力値は大きくばらつかせ、個性的なキャラが生まれるようにする
- ポテンシャル ＝ **成長の速さ**（上限ではない）
  - ポテンシャル自体も戦うと上がる
  - ただし初期値の高い・低いは生まれつきで決まる
- 例
  - 攻500・防20・P50 → 序盤から強いアタッカー。伸びは遅く、防御が弱い
  - 攻100・防150・P120 → 序盤は地味だが、伸びが速く、万能型に育つ
- 狙い：「今強いやつを使うか、将来化けるやつを育てるか」のジレンマ

### ポテンシャルの天井（maximum_potential）
- ポテンシャルは戦うと上がるが、天井より上には行けない
- 天井が上がらないと、ポテンシャルも頭打ちになる
- 天井は**基本は固定**。制限しすぎると夢がなくなるので、例外で上がるようにする
  - **大戦果**を立てると上がる（普通のキャラにも化けるチャンスがある）
  - **特殊スキル**を発動すると上がる
  - 「大戦果」の具体的な条件は、戦闘を作るときに決める

### キャラのタイプ
- **英雄型**：ポテンシャルが高く、どんどん伸びる。光る卵・主人公になりうる王道
- **職人型**：ポテンシャルは並み。ただし1つの能力（防御など）が飛び抜けていて、兵科・スキルのレベルが高い。何でもそつなくこなし、長く活躍する
- **賢者型**：魔力がとびぬけて高く、魔導を極める（2026-10-19 に足した）

### 成長のブレーキ（雪だるま式に強くなりすぎないように）
- **年齢**：年を取ると成長が鈍り、さらに年を取ると能力が下がる
  - ベテランもいずれ衰えるので、若手を育て続ける理由になる
  - **寿命（決定）**：ファンタジーの世界なので、平均60歳、長い人で80歳くらい。寿命が来ると亡くなる（記録は慰霊碑のために残す）
  - **成長タイプ**：衰え始める年齢をキャラごとに変える（寿命から数える）
    - 早熟型：寿命の15〜22年前から
    - 普通型：寿命の6〜12年前から
    - 晩成型：寿命の0〜4年前から（ほぼ最後まで衰えない）
    - 「早熟の天才を短期間で使うか、晩成型を気長に育てるか」の悩みが生まれる
- **負傷・病気**：一時的に弱くなるデバフ
  - 起こりすぎると理不尽なので、「たまに起きる」程度にする
  - 確率はあとから調整できるようにしておく
- 何歳から鈍るか・下がるかの具体的な数値は、動かして見てから決める

## アイデア（検討中。2026-10-19 にまとめた）
すべて「育てた結果が残る」というゲームの核につながる。作る順番は下の「作る順番（新）」。

### 1. 英雄への道を増やす（天才だけが英雄にならないように）
光る卵（約5%）しか英雄になれないと、残り95%が「つなぎ」になってしまう。英雄になる道を4つ用意する。

| 道 | どんな武将か |
|---|---|
| 天才 | 光る卵。何でも伸びる（約5%） |
| **秀才** | 兵科が1つ飛び抜けている。その道を極める（例：白兵SS・得意武器が槍の元帥「疾風迅雷」） |
| 叩き上げ | 会戦で見つけた無名の兵（下の「会戦モード」） |
| 老将 | 長く前線に立ち続けた者（歴戦章） |

- DESIGN の「職人型」を具体的にしたもの
- **兵科適性**（S〜D、まれに SS）。適性の倍率を大きくしないと、秀才が天才に勝てない

| 適性 | 部隊の強さの倍率（案） |
|---|---|
| SS | ×1.5 |
| S | ×1.3 |
| A | ×1.15 |
| B | ×1.0 |
| C | ×0.85 |
| D | ×0.7 |

- **出やすさ**（兵科が9つあるので低め）：1つの兵科でSになる確率3%、SSは0.2%（2026-10-19 に0.5%から下げた）
  - → 全体の約26%が、どれか1つにS以上を持つ（秀才）
  - → 約1.8%がSSを持つ（100人に1〜2人。光る卵よりも珍しい）
  - → S以上を2つ持つのは約3.2%（異例の存在）
- **適性を鍛える**：誰でもSになれると、生まれつきの適性に意味がなくなるので制限する
  - 1段階（B→A）は、その兵科で戦い続ければ上がる
  - 2段階（B→S）は、長い年月か大戦果が必要
  - SS は生まれつきだけ
  - 例：盾B を鍛え上げて S にした「守りの要」は、手間をかけた人だけが作れる
- **複合兵科**：2つの兵科がどちらも S 以上なら開放（例：騎兵S＋鉄砲S → 銃騎兵、騎兵＋弓 → 弓騎兵、重装＋魔導 → 魔導重装、重装＋白兵（槍）→ 重装槍兵）
- **能力値の特化**：防御がとびぬけて高い者は盾兵（重装）向き、のように、能力値の偏りも才能として扱う

### 2. 会戦モード（信長の野望の会戦のように）
- 交戦が始まるとき、「**会戦**」を選べる。選ぶと、副官も含めた部隊どうしの戦い（別の画面）になる
- 副官がいない将校には、会戦のあいだだけ**ランダムな副官（臨時の副将）**がつく
  - たまに強い者が混ざる。**活躍してもしなくても、会戦のあと登用できる**
  - → **無名の叩き上げ**が生まれる入口になる
- 選ばなければ、今と同じ自動の交戦
- 注意：会戦を面白くするには、兵科の相性と地形が必要。**兵科を作ってから**作る

### 3. 記録が残る
- **異名**：記録から自動でつく。「○回やったら」の決まった数字だと、長く遊ぶほど全員が異名持ちになるので、**全体の中での順位**（上位○%）で決める
  - 記録の種類ごとに異名の候補を分ける。武力系は漢字、魔導系はカタカナにすると、異名だけでどんな人か伝わる

| 記録 | 条件（案） | 異名の候補 |
|---|---|---|
| 壊滅させた部隊の数 | 全体の上位5% | 閃光、疾風迅雷、カラミティ |
| 拠点を守った年数 | 20年以上 | 不落、鉄壁、城塞の主 |
| 魔力 | 全体の上位3% | クロノルイン、ヴォイドネクサス |
| 主君のそばで仕えた年数 | 長い | 懐刀 |

- **慰霊碑・国家の歴史**：亡くなった・引退した武将の名前、異名、階級、主な戦果を一覧で見られる画面。作るのは簡単で、愛着がとても強まる
- 必要なもの：**戦死・引退**のしくみ（今は年をとると弱るだけで、死なない）

### 4. 受け継がれる
- **再来（転生）**：亡くなった武将が同じ強さで戻ると、死の重みも、新しい光る卵を探す楽しさも薄れる。なので「**○○の再来**」として
  - 見た目と名前の一部、スキルを1つだけ受け継ぐ
  - 能力は新人と同じで、新兵から
  - 潜在能力に少しだけボーナス
  - 「あの人の面影がある若者」を一から育て直す
- **家名を与える（偏諱）**：主君の名や家名（「フォン○○」など）を家臣に与えると、忠誠心が上がる
  - 与えられる数に限りがある（城1つにつき1人、など）。「誰に与えるか」がゲーム上の判断になる
  - 家名は選択肢から選ぶか、自分で入力する

## アイデア（2026-10-20 の壁打ち）
「決定」と書いたもの以外は検討中。

### 人材の増え方（決定）
- **自動の仕官（初陣）**：プレイヤーが毎月候補から選ぶのをやめる。自国も敵国も同じルールで、若者が自動で仕官する
  - 毎月、国ごとに「拠点の数×3%」の確率でくじを引き、当たったら15〜18歳の新兵が1人仕官する（武将の数が上限＝城×2＋町÷2 より少ないときだけ）
  - 新兵は、空きのある部隊の副官に自動で入る
- **特別な登用**：叩き上げ・捕縛した敵将・滅んだ国の武将・敵の武将の引き抜きのときだけ、時間を止めて「登用する／しない」を選ぶ（上限を超えてよいかは検討中）
- テストプレイの課題だった「自国だけ毎月登用して武将が増え続ける」は、これで直る

### 兵は領地から（検討中）
- 拠点ごとに「人口」を持たせ、毎月そこから兵が集まる。武将が多い小国でも、兵は少ないままになる
- 「将はいるが兵がいない小国」と「兵は多いが将が足りない大国」の違いを出す。政治を入れたら、人口を増やすことが内政の意味になる

### 定員（決定）
- 中間の階級にも定員をつける。国の武将の数に比べた割合で決める（最低1人）

| 位 | 割合 |
|---|---|
| 旅団（連隊長〜上級旅団長） | 20% |
| 師団（師団長〜筆頭師団長） | 15% |
| 准将・管区長 | 10% |
| 統軍将・督戦将 | 8% |
| 地方司令官・総監 | 5% |
| 大将軍・元帥・大元帥 | 5人・3人・1人（ただし国の武将の数より多くはしない） |

- 部隊長より下は定員なし
- **武功昇進（決定）**：勲章を授かると、定員を無視して昇進できる「権利」がもらえる（勲章1つで1段、英雄大綬章なら2段）。権利は持っておけて、半年ごとの人事のときに使うかを選ぶ
- **近衛（決定）**：定員とは別枠で、気に入った武将を置ける席。まずは**首都の特別な部隊**として作る。主君（国王）を武将として作るかは、家系を作るときにもう一度考える（跡継ぎ・王家・継承争いまで広がるため）

### 副官（決定）
- 自分より階級が下なら、誰でも副官になれる（部隊を持つ武将も、大きな戦いでは上官の副官に入れる）
- 部隊を持つ武将が副官に入ったら、その武将の副官は外れて城で待機する（入れ子にしない）

### 地図の操作（決定）
- 重なったコマを選んでいて、そのコマの上にマウスがあるときは、ホイールで部隊を切り替える（それ以外のときはズーム）
- 重なったコマをクリックしたら、そこにいる部隊の一覧をポップアップで出し、チェックで出陣する部隊を選べる
- 敵国の武将も、武将一覧で国を切り替えて見られる（兵科・戦歴・勲章。育成の操作はできない）
- 部隊管理の画面：どの部隊にどの武将を置くかを、ピラミッドの図で見て動かせる（Godot に移ってから作る）

### つながり（検討中）
- **戦友**：同じ会戦を生き延びた武将どうし。一緒に出陣すると少し強くなる
- **師弟**：指南役に育てられた若手は弟子になる。師匠が亡くなると奮起する
- **因縁**：副官を討たれた敵将が「仇」として記録され、何年も後に将軍になって現れる。同じ年に出てきた敵将が「同期のライバル」になる

### 家系（検討中）
- 武将は一定の年齢で妻を迎える（相手は名前だけで、画面には出ない）。子は適性や潜在能力の一部を受け継ぐ
- 子が15歳になったら、初陣のくじが当たったときに、名もない若者より優先して仕官する。家系は「何人入るか」ではなく「誰が入るか」を決めるだけなので、武将は増えすぎない
- 子が生まれる数は絞る（例：数年に1人、多くても3人）。仕官できないまま25歳を過ぎた子は家を出て**浪人**になる
- **浪人**（検討中）：町にいる、どこにも仕えていない武将。特別な登用で召し抱えられる。他国に仕官して、敵として兄弟と戦うこともある（因縁にもなる）
- 跡継ぎがいないときの養子。他国の姫・名家の娘との結婚は、家の格や同盟につながる（外交ができてから）
- 領地を任せた武将の土地から仕官した人は、その武将の家の家臣になる
- ゴールを2つ選べる：一族を何代つなげたか ／ 一代で何か国落としたか

### 国が大きくなると揺れる（検討中）
- 国が広がるほど、武将の中に派閥ができ、不満がたまる。外には包囲網、内には派閥・謀反
- 貴族制：領地を任された武将ほど力を持ち、忠誠が低いと謀反の危険が上がる。強い武将に良い土地を任せたいが、任せすぎると怖い
- **人事**：半年に1回、空いた席に候補を並べて選ぶ（功績・能力・家柄・忠誠）。選ばれなかった人のうち、功績が上だった人ほど不満がたまる。敵国は、功績と能力で自動で決める

### 外したもの
- 「英雄を出すか温存するかの賭け」：1人を特別扱いする仕組みは、全員に愛着を持てるというゲームの軸と合わないので外す

### Godot に移る（決定） → 2026-10-23 に Unity に変えた
- **Unity に変えた（決定）**：もう1つの作品も Unity で作るので、覚えるのを Unity と C# にそろえる。Godot 版はデータを JSON にした所までだったので、失うものはほとんどない。リポジトリは Talent-Conquest をそのまま Unity 用にした。Unity は 6.3 LTS（6000.3.27f1）
- コードは丸ごと移さず、仕様（ルール・数値・画面の作り）だけを持っていって、中身を説明できるように作り直す
- 以下の「Godot」は「Unity」と読みかえる
- 売り物のゲームや作品として見せることを考えて、Godot に移る
- Godot 版は**新しいリポジトリ**に作る（売るとき・作品として見せるときに、Godot 版だけのきれいな形にするため）。Python 版はこのリポジトリに残す
- Python 版は機能を足すのをやめ、答え合わせ用に残す。ゲームの仕組み（画面のない部分）から先に移し、画面はあとで作る
