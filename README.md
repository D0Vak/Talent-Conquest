# Talent Conquest（Unity 版）

育成×国盗りの戦略ゲーム。Python（pygame-ce）版の [Talent-Conquest-Game](https://github.com/D0Vak/Talent-Conquest-Game) から Unity に移している途中。

- ゲームの決めごとは `docs/` にある。作業の初めに読む
  - [docs/DESIGN.md](docs/DESIGN.md)：設計（決まったこと・アイデア）
  - [docs/TODO.md](docs/TODO.md)：テストプレイの課題
  - [docs/ART_SPEC.md](docs/ART_SPEC.md)：武将のドット絵の素材の仕様書
- Python 版は答え合わせ用で、もう変えない。数値の名前やファイルの役割は Python 版の README.md にある
- `tools/export_data.py`：Python 版の地図・地形・名前を JSON にして `Assets/Data/` に書き出す（2つのリポジトリが同じフォルダに並んでいる前提）
- Unity は 6.3 LTS（6000.3.27f1）。両方のPCで同じ版にする（版が違うとプロジェクトのファイルが書き換わって食い違う）
- 作業の初めに `git pull`、終わりに `git push`
- 2026-10-23 に Godot から Unity に切り替えた（もう1つの作品も Unity で作るので、覚えるのを Unity と C# にそろえる）
- コードは丸ごと移さない。Python 版からは仕様（ルール・数値・画面の作り）だけを持ってきて、中身を説明できるように作り直す

## 方針（2026-10-24 に変えた）

Python 版を順に再現するだけだと、作っても「前と同じ」で手ごたえがない。なので、**Unity だからこそできる見た目の改善を先に作り**、Python 版の仕組みは、それに必要な分だけ移していく。下の「段階」は、移すものの一覧として使う。

### 段階1：仕組みを移す

Python 版は答え合わせ用に残し、まず同じ動きを再現する。変えたい所は移し終えてから直す。

- データ：map_data.py・grid_data.py・names.py・地図の絵を JSON などにして `data/` に入れる
- 数値と表：階級23段階、兵科9つ、適性、相性、地形、複合兵科33種、勲位、勲章
- 武将：能力値、素質（魔力持ち・聖力持ち・無者）、寿命、成長タイプ、戦歴
- 動き：移動と道さがし（飛竜の山越え）、包囲、交戦、退却・壊滅、敵のAI
- 時間：毎日・毎月・毎年の処理（訓練、加齢、死亡、昇進、登用）、歴史を30年回す
- 答え合わせ：Unity 版と Python 版を同じ条件で動かし、数字を比べる。Python と C# は同じ乱数の種でも違う数が出るので、2つに分ける
  - 乱数を使わない所（相性の倍率、戦闘の式、階級の表など）：同じ入力で、まったく同じ数になるか
  - 乱数を使う所（寿命、仕官、30年の歴史など）：何回も回して、平均や分布（30年後の武将の数、階級ごとの人数の割合など）が近いか
- map_editor.py・terrain_editor.py はしばらく Python のまま使う

### 段階2：画面

地図 → 右パネル → 育成 → 武将一覧 → 勢力 の順。ここで最初から入れる改善：

- 自動の仕官（初陣）：毎月「拠点の数×3%」で若者が仕官。自国も敵国も同じルール、上限まで
- 特別な登用は選ぶ：叩き上げ・捕縛・滅んだ国の武将・引き抜き
- 重なったコマ：選んでいるコマの上ではホイールで切り替え、クリックでポップアップ一覧、チェックで出陣する部隊を選ぶ
- 敵国の武将も見られる武将一覧

### 段階3：新しい仕組み（この順）

1. 兵は拠点の人口から集まる
2. 中間の階級にも定員（国の大きさに比べた割合）＋武功昇進（勲章で定員を無視して昇進する権利）＋近衛（首都の特別な部隊）
3. 副官は「自分より下なら誰でも」
4. つながり：戦友・師弟・因縁
5. 忠誠・不満 → 半年ごとの人事 → 派閥・謀反 → 貴族制・領地
6. 家系：結婚・子・初陣での優先・養子・浪人・姫。女性武将は約2%
